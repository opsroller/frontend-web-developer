# Reference

These pages describe the plugin's parts as they are: what each one is
called, what it takes and what it returns. They do not teach or argue; for
that, see the [tutorial](../tutorials/first-task.md), the
[how-to guides](../how-to/) and [About the role](../explanation/about-the-role.md).

## The agent

- [frontend-web-developer agent](agent.md): the subagent's sections, triggers and the plugin manifest fields.

## Skills

Building the site:
- [static-sites-and-hosting](skills/static-sites-and-hosting.md): build layers, deploy, caching and security headers.
- [download-pages](skills/download-pages.md): platform detection, release data, store badges.
- [embedding-web-builds](skills/embedding-web-builds.md): event contract, bridges, hosting headers for builds.
- [credits-and-licensing-pages](skills/credits-and-licensing-pages.md): credits, licences, third-party notices.

Quality of the site:
- [web-accessibility](skills/web-accessibility.md): WCAG 2.2 AA thresholds and test passes.
- [seo-and-metadata](skills/seo-and-metadata.md): per-page and site-level metadata, structured data.
- [web-performance](skills/web-performance.md): Core Web Vitals thresholds and budgets.
- [privacy-respecting-analytics](skills/privacy-respecting-analytics.md): measurement rules and events.

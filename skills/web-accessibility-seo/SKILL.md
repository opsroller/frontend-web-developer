# Accessibility and discoverability

- WCAG 2.2 AA: semantic landmarks, alt text, colour contrast, visible
  focus, keyboard-only use.
- Title, description, Open Graph and Twitter card images, canonical URL,
  sitemap, and structured data for software applications.
- Test with a screen reader and at 320 px width before shipping.

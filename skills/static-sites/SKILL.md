# Static sites

- Plain HTML and CSS first, or the static site generator the project
  profile names; JavaScript only for progressive enhancement.
- Mobile-first responsive layout, system font stack or self-hosted
  fonts under an allowed license, no layout shift.
- Budgets: under 200 KB transferred before images on the landing page,
  Lighthouse performance and accessibility 90+.
- Deploy from CI on merge to the default branch (e.g. GitHub Pages);
  preview builds on pull requests where the host supports it.
